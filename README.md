# RedmiBook Manager

Open-source tooling for managing and extending RedmiBook laptop functionality across operating systems.

## Initial target

- Xiaomi Redmi Book Pro 16 2024
- Intel Core Ultra 7 155H

## Current scope

The project is in the research stage. The immediate goal is to understand and document the interfaces used by the factory software and firmware for hardware controls, hotkeys, performance modes, power management, and related platform features.

The first supported device will be the Redmi Book Pro 16 2024. Broader device and operating-system support will be evaluated as the hardware interfaces become understood.

## Status

Research only. No stable public API or supported feature set has been defined yet.
