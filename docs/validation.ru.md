# Что проверено

[English](validation.md) · [Русский](validation.ru.md) · [Документация](README.md)

Границы проверки версии 1.1.5 не означают поддержку любого ноутбука и не заменяют
результат CI конкретного коммита.

| Область | Подтверждение и границы |
| --- | --- |
| Устройство Windows | Ноутбук владельца Redmi Book Pro 16 2024, XIAOMI TM2309/V24C1, BIOS RMAMT6B0P0A0A. |
| Ограничение заряда | SET/GET для 80/100 проверены. На реальной зарядке/переподключении выявлялись сбросы политики; добавлена защита раз в десять секунд. Все сочетания доков, зарядок и сна длительно не проверены. |
| Профили прошивки | SET/GET тихого/сбалансированного/производительного и события Fn+K подтверждены. Владелец наблюдал изменение шума вентиляторов; конкретное потребление/частоты CPU не гарантируются. |
| Экран | Владелец подтвердил переключение встроенного экрана. Внешние и неоднозначно определённые источники исключены. |
| Микрофон | Владелец подтвердил LED и остановку записи при программном mute, обратное переключение восстановило запись; проверено состояние endpoint. Электрическое отключение аудио самой прошивкой не доказано. |
| Энергосбережение Windows | Ручное включение/выключение проверено на Windows 11 25H2 build 26200.6899. Внутренний WNF setter проверяется во время работы; это не публичная гарантия совместимости Windows. |
| Пресеты | Контракты проверяют хранение/миграцию/перевод, предварительную проверку, порядок и ошибки. UI-превью используют имитацию; они не подтверждают все реальные комбинации или переключение схем питания. |
| Тема и запуск | Проверены снимки светлой/тёмной Fluent-темы, движение спиннера и асинхронная загрузка. Offscreen не доказывает поведение GPU и фокуса нативного окна. |
| Установка | Выполнялись обновления разными локальными сборками с сохранением настроек и проверкой совместимости сеанса/ядра. Переустановка той же сборки не считается проверкой обновления. |
| Linux | Подготовлены общий код, адаптеры, сборка и упаковка в CI. Нативные аппаратные адаптеры местами не реализованы. Глубокой проверки Linux и оборудования не было. |

Windows — текущая платформа приёмки. Совпадение модели не подтверждает другой BIOS.
RPM, кривые вентиляторов, температура EC, произвольные пороги заряда и управление
GPU не заявлены как реализованные функции.

Полный локальный `verify` включает сборку, форматирование, clang-tidy, QML,
архитектурные проверки и CTest. CI дополнительно проверяет Windows/Linux
Debug/Release, ядро без Qt и развёрнутые пакеты. Для опубликованного коммита
смотрите фактический [запуск CI](https://github.com/KobaProduction/redmibook-manager/actions).
Наличие документации не доказывает успешную сборку.

[Исследование прошивки](hardware-investigation.md) содержит хронологию проверки;
[правила публикации](releasing.md) — требования к поставке.
