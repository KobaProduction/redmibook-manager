# RedmiBook Manager

[English](README.md) · [Русский](README.ru.md)

Нативный менеджер **Xiaomi Redmi Book Pro 16 2024** на C++20, Qt 6.10.2 и QML.
Версия **1.1.5**. Windows проверена на целевом ноутбуке. Для Linux подготовлены
сборка и упаковка; глубокая проверка рабочего стола и оборудования пока не проводилась.
Для основных функций не нужны WebView, облачный аккаунт и сбор телеметрии использования.

## Возможности

- **Батарея:** ограничение заряда 80% / 100%, мощность заряда или разряда в Вт,
  ёмкость в Вт·ч, напряжение и оценка износа. Фоновая проверка раз в десять секунд
  восстанавливает защиту, если при выбранных 80% заряд продолжается на уровне 80% и выше.
- **Производительность прошивки:** тихий, сбалансированный и производительный режимы;
  состояние синхронизируется между Manager, треем и OSD. Это профили производителя,
  а не гарантия определённых частот процессора, напряжений или потребления.
- **Встроенный экран:** выбор поддерживаемой частоты и набора частот для переключения
  хоткеем и через трей. Внешние мониторы не затрагиваются.
- **Микрофон:** управление проверенным флагом прошивки и LED клавиатуры с последующей
  синхронизацией mute в Windows. Устройство и драйвер не отключаются.
- **Хоткеи:** действия специальной клавиши, включая открытие Manager, трея и отсутствие
  действия; переключение частоты через Fn+S. Fn+K управляется прошивкой и не переназначается.
- **Пресеты питания:** последовательности из профиля прошивки, частоты экрана, схемы
  питания Windows, ручного энергосбережения и яркости. Стартовый пресет с кнопками
  «Экономия» и «Производительность» добавлен, но по умолчанию скрыт в трее.
- **Трей:** компактная панель, настройка элементов состояния и порядка пресетов.
  Левая кнопка открывает панель, правая — меню.
- **Оформление и обратная связь:** OSD и звук отключаются независимо; Fluent,
  системная/светлая/тёмная темы, переключение русского и английского без перезапуска.
  Стандартные подписи пресета переводятся, пользовательские названия сохраняются.
- **Настройки и обновления:** настройки принадлежат демону; есть сброс, ручная и
  необязательная ежедневная проверка обновлений. Сброс возвращает заряд до 100%,
  сохраняя текущий режим экрана. Загрузка обновления запускается пользователем.

## Совместимость и установка

Запись в прошивку проверена только для **TM2309 / RMAMT6B0P0A0A**.
Другая модель RedmiBook или версия BIOS не считается совместимой автоматически.
Неподдерживаемые функции отсутствуют в каталоге возможностей; ошибки выполнения
показываются отдельно. Подтверждение настройки прошивки не доказывает физическую
остановку зарядки во всех условиях.

Пакеты доступны в [Releases](https://github.com/KobaProduction/redmibook-manager/releases):
Windows x86_64 — установщик NSIS и переносимый ZIP; Linux x86_64 — DEB и tar.gz.
Разрабатываемая версия публикуется как неподписанная alpha-сборка.

В Windows запустите установщик и подтвердите UAC. Программа устанавливается в
`Program Files/Koba Production/Redmibook Manager`; регистрируются машинная служба
и фоновый компонент пользовательского сеанса. Настройки при обновлении сохраняются.
Открывайте Manager из меню «Пуск» без прав администратора. Закрытие окна и трея
не останавливает хоткеи, OSD и защиту батареи. Распаковка ZIP сама по себе
не регистрирует фоновые компоненты.

## Архитектура и расширение

`apps → presentation / adapters → application → domain`

Домен и прикладная логика используют стандартный C++. API Windows/Linux,
хранилище и IPC находятся в адаптерах; точки сборки подключают поддерживаемые
возможности конкретного устройства и ОС. Демон сеанса хранит настройки в RAM
и передаёт изменения клиентам через IPC. Машинная служба владеет привилегированными
политиками прошивки. Manager и трей не редактируют файл настроек напрямую.

Нативные операции выполняются асинхронно вне GUI-потока. Обновления приходят
по событиям, а сверка раз в десять секунд восстанавливает пропущенное состояние.
Экран батареи временно запрашивает выборку 100 ms, 1 sec или 5 sec; при уходе
с него подписка снимается. Новые BIOS и модели подключаются через квалифицированные
адаптеры с проверкой чтения/записи, без ветвлений по названию модели в QML.

## Сборка и проверки

Нужны компилятор C++20 (MinGW 13.1 в Windows), Qt **6.10.2**, CMake **3.30+**,
Ninja, Python **3.12+**, clang-format/clang-tidy **19**. Для Windows также нужны
PowerShell **7** и NSIS **3.11** для установщика. Укажите `QT_ROOT` на каталог Qt.
Зависимости Linux перечислены в [CI](.github/workflows/ci.yml).

```powershell
# Windows
cd <checkout>
cmake -P tools/install-hooks.cmake
./tools/dev.ps1 -Action verify -QtRoot $env:QT_ROOT
# Упаковка проверенной сборки без повторного verify:
cpack --config build/release/CPackConfig.cmake
```

```sh
# Linux, инструменты Qt/компилятора/LLVM в PATH, QT_ROOT задан
cd <checkout>
cmake -P tools/install-hooks.cmake
cmake --workflow --preset verify
cpack --config build/release/CPackConfig.cmake
```

`cmake --build --preset release` собирает приложение. Пресеты configure/build/test
`core` проверяют внутренние слои без Qt. При разработке запускаются затронутые
проверки, перед checkpoint-коммитом — один полный `verify`. CI независимо собирает
Windows/Linux в Debug/Release и проверяет установленные пакеты. Push в `main`
создаёт артефакты; ветка `release` публикует alpha после успешной матрицы.
